Text Adventures

This first game came from the Marshall Cavendish Input Magazines (1984-1985).
A 52-issue weekly partwork magazine and home computer programming course. It taught coding (primarily BASIC) and hardware concepts across popular 1980s home computers like the Sinclair ZX Spectrum, Commodore 64, Acorn BBC Micro, Dragon 32, ZX81, Vic 20, and Tandy TRS-80.

The complete archive is available via the Internet Archive Input Magazine Scans. It can be found in other sites 8-Bit Software PDF version.
